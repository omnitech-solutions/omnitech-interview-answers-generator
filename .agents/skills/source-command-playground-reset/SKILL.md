# source-command-playground-reset

Use this skill when the user asks to run the migrated source command `playground-reset`.

## Command Template

# Reset Playground

Run:

```bash
interview-answers playground reset
interview-answers playground show
```

Report the confirmed empty/default state. This clears the live form; it does not
delete saved answers.
