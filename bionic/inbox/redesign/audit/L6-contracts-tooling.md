# L6 audit: contracts, shared packages, tooling and test boundaries

## 1. Scope and method

Read: package.json, tsconfig and src of the ten slice packages; root package.json, turbo.json, biome.json, lefthook.yml, tsconfig.base.json, tsconfig.json, vitest.config.ts, vitest.package.config.ts, apps/web/vitest.config.ts, pnpm-workspace.yaml, compose.yaml, .env.example, README env tables, scripts/package-boundaries.test.ts. No .github directory exists (no CI in repo; the only gate is lefthook pre-push `pnpm verify`).

Ran (read-only): `pnpm exec vitest run scripts/package-boundaries.test.ts scripts/dev-build-graph.test.ts scripts/dev-env.test.ts --project node` (3 files, 19 tests passed, covers INV package-boundaries-hold). Read Biome 2.5.5's `configuration_schema.json` for real rule names. Reused the baseline Knip output (runs/before/knip-production.json) for my packages. Env inventory is a static grep: it misses reads made through helpers such as `whole(env, "AGENT_WORKER_*")`, so "undocumented" is a lower bound.

Not inspected: Swift side (L5), apps/web internals, products internals beyond cross-references, `pnpm lint`/`typecheck`/full coverage run, Docker.

## 6. Already good

- package-boundaries-hold passes; it covers apps/*, product-to-product, adapters, contracts-to-contracts, database isolation, neutral session core and companion edges.
- `catalog:` pins typescript, vitest, zod (4.4.3 with a documented reason), react, tsx, types; no shared dev-dep version drift. Strict TS flags (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noPropertyAccessFromIndexSignature`) inherited by every package with no overrides.
- ACTIVE_SESSION_LIMITS is a frozen, commented single table used by observation.ts and backend; the wire JSON schema and corpus are generated from zod, committed, and guarded by a drift test (wire-schema.test.ts) and consumed by Swift conformance tests.
- interview-contracts index.ts is a curated named export list, no `export *`; credential helpers use WebCrypto, not node:crypto.
- Per-package scripts (build/typecheck/test/lint) are consistent across 28 workspaces except terminal-gateway `lint`; turbo `typecheck`/`test` depend on `^build`, so no stale dist.
- lefthook: pre-commit lint+format in parallel, pre-push full verify. compose.yaml and docker/postgres are minimal and use a dedicated port.
