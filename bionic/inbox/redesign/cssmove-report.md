## Cascade order
Moved rules now sit at the top of `studio.css`, so they come after every kept shell rule and before the rest of the studio CSS, exactly as the whole of `styles.css` did before. The only change is against kept shell rules that were LATER than a moved rule: global `select`/`h1`/`h2`/`p` (type selectors, lose to any class selector either way, and every moved selector contains a class), `.studio-page` (the only elements with that class carry no other moved class in the four interview call sites), and Presentation-only rules (elements never carry library or studio classes). No property winner changes; the computed-style comparison below confirms it.

## Proof (Chromium, light and dark, 1280x800 and 390x844)
Harness: a temporary spec (copy in the scratchpad `css/zz-css-shots.spec.ts`, deleted from the repo) took a PNG and a computed-style dump of EVERY element (all properties, sorted) for 18 surfaces x 2 viewports x 2 themes = 72 captures per run: home, workspace, briefings, documents, knowledge (landing and article), rehearsal, live setup, live active, live paused, live ended, tenant workspace, tenant knowledge, integrations, Presentation home, sign-in, signed-out, native sign-in. Runs: `before` (original CSS), `before2` and `before3` (original CSS again, for the noise floor), `after`, `after2` (moved CSS).

Computed styles, original vs moved (before3 vs after and after2): 0 differing elements on every surface, except live-active (5 elements) where the only changed values are `--level` and the bars' `transform` of the microphone meter, which follow the fake microphone's audio and also differ between two runs of the ORIGINAL css.

Pixels: NOT literally zero, and I do not claim it. Identical-CSS reruns are themselves not pixel-stable: original vs original differ by up to 237 pixels in 3 to 5 captures (for example home dark desktop 101 px, live setup dark desktop 72 px, delta 1 to 2 of 255 per channel, soft shadow dithering), plus the live microphone meter. Original vs moved: 147 and 192 differing pixels in 5 to 8 captures (home phone dark 31, knowledge phone dark 46, live ended 12 and 25, live paused/active light 8, all at a channel delta of 1, and live-active at the same mic-meter bars, delta up to 89), a different set of files on each run and within the same range as the identical-CSS reruns. Per-pair numbers are in the scratchpad (`css/final.md`, `css/after*.md`, `css/noise.md`).
